## In regards to info augmentation
### Douglas Engelbart

It's something that I've come to respect, Engelbart's pursuit of improving human access to the input and navigation of human-readable information. I find that the Apple Lisa and Xerox PARC's Lisp Machines miss the point, though they make it easy to experience the system's access to info. In this folder, I have specific objectives to achieve.

### Hardware
To do this I am using the following hardware:

1. Dell Latitude E6400
2. Belkin Nostromo n52 Speedpad
3. 320GB SSD

The Nostromo stands in for the chorded keyboard used by Engelbart and team in the ASI, with macros for markdown, alt-tab and program-specific shortcuts set up in the Profile Editor. The SSD is just to speed things up, as I could easily do this with a hard drive if I so needed to.
### Software
The software is relevant to this process as I needed a way to click between markdown files and access headers from a file that references it. Here's the software I'm using.

1. Markdown Monster, with a key kindly provided by the archivist.
2. Nostromo N52 software, where I'm setting up quite extensive macros to simplify the process, in the vein of the chorded command inputs, but with one key for each action.
3. Supermium, a browser specifically tuned for Windows 7, with privacy-respecting changes and performance enhancements.

The markdown issues I had with everything else was that either it didn't support back and forth navigation like a browser, it lacked cross-file linking or both. With Markdown Monster, I don't have both, but at least I have the latter. That's good.

### Already seeing results
The initial learning curve was because I was trying to figure out how best to use my Nostromo for markdown purposes. The first 3 buttons are currently used to make the 3 header levels that I use, with a space at the end to get right to typing. Button 4 makes the following input with 3 arrows left to start writing the link.: \[\]\(\). Button 10's macro is Ctrl+F to start searching, since the shortcut is pretty ubiquitous as a way to pull up the search prompt. Orange button is used as a one-time alt-tab, because I can't hold the button to do a keyboard-only multi window switch in my current configuration. The scroll wheel on it has been bound to page up/page down to shoot through a document, where my mouse wheel or middle click drag will pick it up afterwards.

However, I still have buttons to assign, things to learn about Markdown.

### Why am I doing this?
Simple: Douglas Engelbart inspired me, more than Apple's engineers with the Lisa and Macintosh, though they're still excellent in their own right. While the Lisa focused on making information accessible to the average officeworker, the NLS hardware, the Augment Browser and Hyperscope 1 and 2 reveal a world of intellectual and academic possibilities that could only be found if you were actively looking for it. It's this that inspired me to try and make a similar ecosystem with little coding knowledge. Check [this video](https://www.youtube.com/watch?v=2nm47PFALc8) to see what I'm talking about.

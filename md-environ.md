# My Flexible Markdown Environment
### My setup
You may be wondering why I'm so obsessed with this. Engelbart's vision represented a jump in how you can review information on the fly. An environment like this where I just pile up MD files, however would not be a good setup for a distributed knowledge base. I would have to get things set up in folders.

Nonetheless, I love my current setup as a personal knowledge base. Markdown is easy, and it's even easier when using my Nostromo (or the Azeron if I was on Windows 10). Since markdown converts to HTML, if I wanted to make a simple public knowledge center, I can do just that by, instead of jamming a markdown interpreter into the site, actually converting MarkDig into HTML itself.

I could also do this with [Gemini](https://geminiprotocol.net/) (not to be confused with the Gemini AI you damn clanker lovers), I would just have to rewrite all of the MD-specific portions in GemText. If I needed to expand my methods of rendering information, I can learn LaTeX down the line. After this entry there will be much more cross-referencing as I want to actually use this like the NLS I'm inspired by.

### My workflow
At its core, I just make MD files and link them back and forth as needed. The ability to go back to a prior tab would be good, but I don't have that right now. I use the Nostromo for everything Markdown and text editing related: headers, search, links, selecting entire words, etc.. I even have undo and redo here.

I have my scroll wheel set to page up and page down to yeet myself through larger MD files versus my mouse, thumb button set to alt-tab and the orange button set to make a new file. This new file almost immediately gets the save-as treatment to work around a minor quirk with Markdown Monster. At least it beats VS Code by a long shot.

### About that Nostromo...
"Why? You have many other options, like your Azeron Classic, or you could get one of Razer's offerings." Simply put, I read about how the Nostromo N52 is an absolute tank. Another matter is the software compatibility. Windows 7 is currently the best OS I have, but the drawback is that Azeron's software, much less any Razer Synapse newer than versions from 2020 will refuse to run with VxKex, except for versions that natively supported the original Razer Tartarus for example.

It also has shift inputs: Red Shift, Green Shift, and Blue Shift. Similarly, the Saitek Gamer/Cyborg Command Unit has a switch for those 3 modes. However, it pales in comparison to the n-key shift that the Azeron and newer devices can do. As such, there are only so many combinations you can use.

That doesn't bother me much unless I was chording my controls, in which case the lack of software for Win7 is inexcusable for this purpose.

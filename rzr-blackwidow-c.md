# Razer Blackwidow Chroma (Synapse 2 Offline Only)
This is the keyboard that I'm currently using, and a successor to the Blackwidow, with 5 dedicated macro keys and a reasonable set of media functions. As the title implies, I'm using a strictly-offlined version of Synapse 2 for use with it. It's a good keyboard from when Razer still made quality hardware and electronics.
### In regular use
This is being used for my laptop-to-desktop setup, and was used for my Orange Pi turned crazy old Hackintosh after I switched out from the Lenovo keyboard. It also succeeds my Redragon Yama after years of using it. Geez, typing has never felt better. The Yama was an upgrade from the older keyboards, but switching to it from the old Blackwidow was an utter downgrade I realize.


# The keypads that power this environment
I'm going to introduce you to the keypads, both owned and looking to buy, that empower such a seemingly convoluted knowledge base such as this, from the Belkin N52 to the Hori Tactical Commander PS4.
## Owned
### Belkin Speedpad N52 Nostromo (Used)
This is my current *tank and workhorse*, mostly because the software for the Azeron line is just incapable of running on Windows 7. Starting this device up was trickier than I thought, as the driver installer did not work and I had to find a valid ISO of a CD that had it. Since then, however, it's become my wrist-saving navigator and Markdown speeder.

The software permits very long macros, and delays help with software that won't respond to input until a menu appears, say World of Warcraft or Destiny 2. However, because of my work here, I don't need menus, so whenever I type out my shortcuts, I disable registering delays between them, making for a very snappy experience. The only drawback is that this does not support built-in profiles, unlike the Azeron Classic below.


### Azeron Classic (Not used currently)
The Azeron Line is an excellent series of 3D-printed keypads specifically designed to *reduce the distance between you, your buttons and your thumbstick*. The Azeron Software has more limited macros, but has incredible layering capabilities, making up for lost time on said smaller macros (though I've never tried any huge macros like I am on the Nostromo). The reason this is left unused compared to said Nostromo is the software. It hates Windows 7, and since I updated the firmware somewhat recently, older Win7 compatible versions would despise the fact that it is using newer internal software guts.

If I decided to do this on Windows 10, or migrate my experiment to it, it will serve me well.

UPDATE: I remembered a cheeky workaround for this problem, one that I used to handle the lack of keyboard diagonals on the Nostromo. By setting all of my inputs to DInput, it can be picked up by AntiMicroX, similarly to the [Hori TAC Pro](#hori-tactical-commander-pro) referenced here. That means I can use it and test it out for this purpose.

### Hori Tactical Commander Pro
This represents one of Hori's various stabs at bringing one-handed keypads to the console market. It's compatible in various ways, from PS4 controller and right stick mouse to PC keypad and mouse. Being warned about the crummy software, I opted to use AntiMicro X the first chance I got. It works well, but drawbacks prevent it from being as good as the Azeron line, the Nostromo, and presumably the Saitek Cyborg/Gamer Command Unit, as certain buttons are dedicated to modifying the stick's movement (say to go into a walk at full tilt), preventing modifications to the buttons in question.

## Wanted
### Saitek Cyborg/Gamer Command Unit
The Command Unit represents something I never really thought of in terms of keypads, having known about the Tartarus, Orbweaver and Diti for a while now. It appears really compact, at least on eBay listings, and it's clear that it's meant to cram down into a small package for transport purposes. If I'm on the go and can't rest for long, I want this with me. The drivers and software have already been downloaded, and are waiting for me to get one of these bad boys.

The only minor drawback is that it can only move between the three profiles with a *3-way flat switch*. I don't mind, I already had to set my Nostromo's Red Mode to toggle, and it works that way.

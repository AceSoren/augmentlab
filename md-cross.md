# Markdown Cross-Linking
This is the one thing I wasn't going to compromise on, because that would have hampered my ability to reference information quickly. By being able to cross-link and navigate to headers in other files, I can relentlessly cross-reference and examine any data that I have on hand. That's what it means to have a better understanding and storage of information.

### In comparison to NLS
NLS, Augment and Hyperscope generally focus on what you can do with data: read, cross-reference, look up, add new data, modify data when needed and change how you read said data. It does this with a rather minimal UI, and a complicated one to boot, which is eased by the use of a 5-key contraption to input combinations. Here, I use macros to quickly make headers and links, copy and paste text, and best of all, save-as (MM has a quirk saving the first time, nothing major) and new file shortcuts.

In the UI, left side numbers and letters show the permanent ID of the "statement", which is a line. On the right, there are the "purple numbers" which is the line count relative to the document. 

### My Markdown navigation method
Long story short, I make as many references as I think I'm going to need and then some. I have "universal controls" as a concept, which is just me pasting the return to index and the ability to go back up the document like you see at the end. So far I don't know how to reference specific words in Markdown, and I don't think it's possible from prior troubleshooting, so instead I focus on linking headers in references or relative links.

Markdown Monster and some other editors allow you to link not only to other markdown files, but also their header sections. Take this link for example: \[Reference to other\](other.md#TimeTrial\). other.md has an H1 header named TimeTrial, and because MM knows that you are referring to the header, it will automatically open the file and navigate there.

In Markdown Monster, searches can be done in either the editor or in the preview, in case you need to look up a piece of Markdown functionality. Most of the time, since I'm looking for information, I'll instead search on the preview side. That will work for my purposes.

The more I read about Markdown Monster, the more I knew that it was the right choice for me. If I highlight a word or set of words and hit F3, it will skip the prompt and use the selection as its input. Beautiful piece of kit.

# One-liner log: Nostromo N52
This is the first pad that I turned to for this project, since I was tinkering with it to see how well it would work for this very laptop. So far it has been an excellent experience, save for drivers. I think that the versions of the software I downloaded only had the 32-bit drivers until I lucked on an ISO of it.

It's unlocked a world of data handling by itself. Paired with Markdown Monster, it's an absolute beast like the chord command input device of the NLS. However, I'd like to talk a bit about the time I used it to play games, since that's where most of my experience is.

### Minor software hitches
Aside from the driver issue on Windows 7, the quirk I had to deal with was in regards to the D-pad and how it worked. Each input is a separate input, like it should be, but on PC, you would expect those inputs to be combined, right? Nope, the Nostromo software takes it literally. To sidestep this inability to input keyboard diagonals, I took to leaving its default mappings and passing it off to AntiMicro (now AntiMicroX), which registered these diagonals as expected.

### Destiny 2
There was a time when I trusted Bungie to at least keep themselves intact, so after playing with the Azeron, I bought the Nostromo as my backup device in case something broke hard enough. This is where I got first-hand experience of the above problem and the resulting workaround. The D-pad itself is somewhat stiff and didn't feel like it worked well for controlling my Guardian, but now I realize I was just holding it all wrong at time of writing.

### As a data processing companion
This is where I really got into the meat and potatoes of the macros and shift inputs. Suddenly everything was quickly accessible, even when I was without the quick access to buttons on the Azeron. It's such a smashing success that I have the other 3 keypads (one owned and 2 wanted) in my index like this one just to log how they do for this purpose.

Long story short, my shortcuts are a combination of text editing and Markdown macros and syntax, with some for Markdown Monster to take advantage of it. First row is first 3 header types, link, and reference. Second row is undo, redo, save, save as and find. Third row is copy paste, select word left and select word right. The orange button makes a new file. The mouse wheel up and down are mapped to page up and page down to yeet through pages with.

That's just the first layer, the Red layer, has additional functionality, with anything not mapped used as normal. First row is superscript, subscript, normal (don't have a mapping to use), HTML and HTML End. Second row is normal, bold, italics, quote, and F3 which is find next. Third row is preview which opens an HTML render, page up, page down and alt+tab.

Note how *I seldom used single keys to describe what I'm doing.* Those are MACROS, baby! Large ones too. All the keypads that I'm looking into support macros, either with first party or third party software.

### After some inactivity
It took me a brief moment to actually get my head back straight as I flailed around a little. I'm back to using it right thankfully. I wonder, if I start using the other keypads, will this idea become an unmaintainable mess?

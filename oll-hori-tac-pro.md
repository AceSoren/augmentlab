# One-liner log: Hori TAC Pro
##### DISCLAIMER
There are actually two models to this, the M1 and M2. Here I'll be referring to the M1 because I want it (and now use it), but this will apply to both since they're nearly the same. Without further ado, let's begin.

### Conditions to use the thing
I need to buy this first. Then I'll set the controller to PS4 controller mode, using AntiMicroX to more accurately map macros and inputs like I intend, without the original software's interference. This is needed because my macros are long, complex and unable to be used by the original software.

### An interesting take on keypads
Hori has always been known for their quality, but what catches my eye is that, instead of 5 columns like most keypads, there are 4, akin to a standalone keypad but with more buttons and a focus on gaming. Like the Azeron, it has a joystick at the thumb which is adjustable (PS5 version only I think). The wrist rest is freely adjustable by pressing in the lock. It has a USB port with which to connect a 4-button gaming mouse, which emulates the right stick.

However, that same emulation results in stick-related quirks that affect how well you move the cursor. At first glance, when watching reviewers play Black Ops and other games, it seems to be similar to the challenge faced by NLS users, offset by the fact that they use the thing a lot and thus constantly compensate. I wonder if I can do the same and thus free up a USB port.

### In games in general
To be written once I have experience with it. However, having a thumbstick is always good for navigation.

### As a data processing companion
I'll write more about this, but due to the fact that it has more profiles than the Nostromo natively, I have no doubt that I'll be able to do everything I need to at the desk. However, with AntiMicroX, I have 1 more profile with 9 instead of 8. The stick might be an issue unless I change the trigger zones. Oh well! Geronimo!!
# 04/19/26

### Prototyping
So, to test the keypad in an already established environment, I decided to actually prep it for use with the markdown labo. It was there that I actually learned of the additional quirks of Antimicro. Until now I only used it for single inputs, but now it seems as though I stepped into sacred ground whereas the Nostromo's configuration system was welcoming to beginners and tourists alike. After learning the quirks, I started setting it up. A while later, I have the 3 header macros, as well as links and references. I have some things to say about this thing.

### Ergonomics
This is one of the more unique keypads, even though it still gets beat by the Azeron Classic. It IS 5-column, but the first 4 columns from the right are aligned, giving the impression of a 4-column like a numeric keypad. The far left buttons are larger and heavier, presumably because they're tool or long-term use buttons. The way the hand fits is rather dynamic, as Hori apparently took into account multiple grips or rests. Lots of reviews I watched also enjoyed the ergonomics, and I can see why.

### Official software
Okay, this is funny, Hori appears to not be known for their software, though they did seem to do alright with the TAC FF14. The software is incredibly limited on PC, mainly due to how they built the thing for PS3/PS4. The FF14 software was better because it was tuned for a single game though it was useful elsewhere. Let me explain...

The biggest hitch is twofold: the mapping is incredibly limited and the button count for Antimicro is shrunken by a few shortcut buttons, namely Walk, Quick and Snipe. Those buttons are outright missing. Truth be told, however, it's probably due to the insufficient button count of the original Dualshock 4. This is probably where the original hardware would shine, if I was using the keypad for gaming.

### Antimicro, my solution to the official software fails
This is something that I've used for a really long time. It's been my saving throw tool ever since I first ran into the complex controls of HIGH-MACS Simulator. However, like I said above, I never really touched macros until now. An issue that seems to persist with Antimicro X, its successor, is that repeated inputs of the same key appear ignored, at least until the "keyboard" registers how long it was held down. To fix this, I used a combination of Hold and Release configurations, as well as some other tomfoolery that I forgot how to describe already.

However, once configured, the macros react much faster than the Nostromo software and N52 Nostromo ever will, and I think it also beats the official Azeron software in macro input speed. It's a nice bonus, but what about the actual macros themselves? I'd say it's as good as the Nostromo and Azeron software in that respect. If I found myself without the Azeron software in a grid down situation, Antimicro can come to save the day.

# 04/20/'26, midnight
I've continued working on the Antimicro setup. It's a lot more involved than expected, but that's probably due to inexperience. On that note, I was setting inputs to 0ms delay, expecting all inputs to happen at once, but Antimicro doesn't do that. It doesn't have input release either except for specific mechanisms. I also realize that the input time is for how long a key is held down as the sequence continues. It doesn't halt the sequence in other words, which helps me understand how to do complex things like shift selecting words.

That right there was the biggest hitch, and what was causing a lot of issues. No Hold or Release necessary. Got it fixed.

This is good, but due to the control-only buttons, I had to wriggle around the problem a fair bit. Being able to directly access them as DInput buttons would be preferable. Oh well.

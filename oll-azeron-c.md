# One-liner log: Azeron Classic
Ah, the Azeron Classic. After badgering my dad a little to get it, it opened my eyes with how efficient it was to use. Not only that, but the macro system also eased the amount of things I have to do. It was here that also realized just how 3D-printed parts feel and realized I should get the Nostromo as a backup.

### The software
The software, after some versions, dropped Windows 7 support, which, for my current setup, caused my initial attempts to map it to blow up in my face. Even VxKex NEXT, a kernel extender, failed to save the day. However, with proper configuration (and a microcontroller reset), I can use this with AntiMicro/AntiMicroX to serve the same purpose as the original software.

### Destiny 2
The very first game I tested this on, since I was playing it extensivley at the time. I really enjoyed the ease of use and the few macros that I had set up for when i flick my hand up, which were menu-related. After that stint, however, it ended up in storage. Now I brought it back out for this experiment of mine.
